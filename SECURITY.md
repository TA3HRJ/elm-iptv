# Security / Güvenlik

## English

Please **do not** report security problems in public issues. Write to **errhan@hotmail.com** with the app
version, the device and the steps to reproduce. You will get an answer within a week; fixes go into the next
release and the release notes mention them once users can update.

In scope: the app itself, for example the home-network transfer page (backup, error and memory logs), backup
encryption, the parental PIN and kids profiles, and how playlist passwords are stored.

Only APKs from this repository's Releases page, signed with the developer's key, are official. Copies from other
sites may be modified.

## Türkçe

Güvenlik sorunlarını lütfen herkese açık "issue" olarak **bildirmeyin**. Uygulama sürümü, cihaz ve sorunu
tekrarlama adımlarıyla **errhan@hotmail.com** adresine yazın. Bir hafta içinde yanıt alırsınız; düzeltme bir
sonraki sürüme girer ve kullanıcılar güncelleyebildiğinde sürüm notlarında belirtilir.

Kapsam: uygulamanın kendisi; örneğin ev ağı aktarım sayfası (yedek, hata ve bellek günlükleri), yedek şifreleme,
ebeveyn PIN'i ve çocuk profilleri, liste şifrelerinin saklanması.

Yalnızca bu deponun Releases sayfasındaki, geliştiricinin anahtarıyla imzalı APK'lar resmidir. Başka sitelerdeki
kopyalar değiştirilmiş olabilir.
